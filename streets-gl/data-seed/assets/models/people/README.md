# Passenger figures

Drop `.glb` human models here (or import them from the Sketchfab browser into the
**People** category, or upload them from Settings → Passengers).

Any human model works: it is re-origined to stand on the platform and scaled to
1.75 m automatically, whatever units it was modelled in. Keep them low-poly —
a platform can draw up to 40 of them at once, and several platforms are visible
at a time.

The game always has the built-in procedural figure available, so crowds work
even when this folder is empty.
